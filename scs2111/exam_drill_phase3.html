Phase 3 Master Exam Bank: Cisco CLI Syntax & OSI Reference Models

Complete 70-question university question bank covering OSI/TCP-IP layer mapping, PDU transformations, TCP handshake sequence diagrams, Cisco IOS CLI switch syntax, and VLAN routing.

Part 1: Easy / Foundational Questions (Questions 01 – 30)

Question 01 • Easy [4 Marks]

What is the OSI Reference Model?

Official Model Answer & Marking Scheme [4 Marks]:

A 7-layer theoretical architectural framework standardizing network communication functions.

Question 02 • Easy [3 Marks]

How many layers are in the OSI model?

Official Model Answer & Marking Scheme [3 Marks]:

7 layers.

Question 03 • Easy [5 Marks]

List all 7 OSI layers in order from Layer 7 to Layer 1.

Official Model Answer & Marking Scheme [5 Marks]:

7: Application, 6: Presentation, 5: Session, 4: Transport, 3: Network, 2: Data Link, 1: Physical.

Question 04 • Easy [4 Marks]

List all 4 TCP/IP layers in order.

Official Model Answer & Marking Scheme [4 Marks]:

4: Application, 3: Transport, 2: Internet, 1: Network Access.

Question 05 • Easy [4 Marks]

What is a PDU (Protocol Data Unit)?

Official Model Answer & Marking Scheme [4 Marks]:

The formatted data block passed across layer boundaries during network transmission.

Question 06 • Easy [3 Marks]

State the PDU for Layer 4.

Official Model Answer & Marking Scheme [3 Marks]:

Segment (TCP) / Datagram (UDP).

Question 07 • Easy [3 Marks]

State the PDU for Layer 3.

Official Model Answer & Marking Scheme [3 Marks]:

Packet.

Question 08 • Easy [3 Marks]

State the PDU for Layer 2.

Official Model Answer & Marking Scheme [3 Marks]:

Frame.

Question 09 • Easy [3 Marks]

State the PDU for Layer 1.

Official Model Answer & Marking Scheme [3 Marks]:

Bits.

Question 10 • Easy [4 Marks]

What is the primary role of Layer 4 Transport Layer?

Official Model Answer & Marking Scheme [4 Marks]:

End-to-end communication, port process multiplexing, flow control, and error recovery.

Question 11 • Easy [4 Marks]

What is the primary role of Layer 3 Network Layer?

Official Model Answer & Marking Scheme [4 Marks]:

Logical IP addressing, packet routing across intermediate networks, and path selection.

Question 12 • Easy [4 Marks]

What is the primary role of Layer 2 Data Link Layer?

Official Model Answer & Marking Scheme [4 Marks]:

Physical MAC addressing, framing, and media access control across local LAN segment.

Question 13 • Easy [4 Marks]

What is the primary role of Layer 1 Physical Layer?

Official Model Answer & Marking Scheme [4 Marks]:

Transmitting raw bit streams over physical copper wire, optical fiber, or wireless RF.

Question 14 • Easy [3 Marks]

State default port for HTTP.

Official Model Answer & Marking Scheme [3 Marks]:

Port 80.

Question 15 • Easy [3 Marks]

State default port for HTTPS.

Official Model Answer & Marking Scheme [3 Marks]:

Port 443.

Question 16 • Easy [3 Marks]

State default port for SSH.

Official Model Answer & Marking Scheme [3 Marks]:

Port 22.

Question 17 • Easy [3 Marks]

State default port for DNS.

Official Model Answer & Marking Scheme [3 Marks]:

Port 53.

Question 18 • Easy [4 Marks]

What is the main difference between TCP and UDP?

Official Model Answer & Marking Scheme [4 Marks]:

TCP is connection-oriented and reliable (guaranteed delivery); UDP is connectionless and lightweight (fast, no retries).

Question 19 • Easy [4 Marks]

State the 3 flags used in TCP 3-way handshake.

Official Model Answer & Marking Scheme [4 Marks]:

SYN, SYN-ACK, ACK.

Question 20 • Easy [4 Marks]

What is an Access Port on a switch?

Official Model Answer & Marking Scheme [4 Marks]:

A switch port carrying traffic for a single untagged VLAN to end-user devices.

Question 21 • Easy [4 Marks]

What is a Trunk Port on a switch?

Official Model Answer & Marking Scheme [4 Marks]:

A switch port carrying traffic for multiple tagged VLANs between switches or routers.

Question 22 • Easy [4 Marks]

What is IEEE 802.1Q tagging?

Official Model Answer & Marking Scheme [4 Marks]:

Frame tagging protocol that inserts a 4-byte header containing a 12-bit VLAN ID into Ethernet frames.

Question 23 • Easy [3 Marks]

What is a Native VLAN?

Official Model Answer & Marking Scheme [3 Marks]:

Untagged VLAN on an 802.1Q trunk link (default VLAN 1).

Part 2: Medium / Intermediate Questions (Questions 31 – 40)

Question 31 • Medium [5 Marks]

CLI command to assign port to VLAN 10.

Official Model Answer & Marking Scheme [5 Marks]:

switchport access vlan 10

Question 32 • Medium [5 Marks]

CLI command to configure trunk mode.

Official Model Answer & Marking Scheme [5 Marks]:

switchport mode trunk

Question 33 • Medium [5 Marks]

CLI command to save running config to startup config.

Official Model Answer & Marking Scheme [5 Marks]:

copy running-config startup-config (or write memory)

Question 34 • Medium [5 Marks]

CLI command to view active CAM table.

Official Model Answer & Marking Scheme [5 Marks]:

show mac address-table

Question 35 • Medium [6 Marks]

Explain Encapsulation step-by-step down OSI stack.

Official Model Answer & Marking Scheme [6 Marks]:

Data -> Add Transport header (Segment) -> Add IP header (Packet) -> Add MAC header & FCS (Frame) -> Encode as electrical/optical signals (Bits).

Question 36 • Medium [6 Marks]

Explain Decapsulation step-by-step up OSI stack.

Official Model Answer & Marking Scheme [6 Marks]:

Receive Bits -> Strip MAC header & verify FCS (Frame) -> Strip IP header (Packet) -> Strip Transport header (Segment) -> Deliver Data payload to Application.

Question 37 • Medium [4 Marks]

State TCP header minimum size.

Official Model Answer & Marking Scheme [4 Marks]:

20 bytes.

Question 38 • Medium [4 Marks]

State UDP header size.

Official Model Answer & Marking Scheme [4 Marks]:

8 bytes.

Question 39 • Medium [6 Marks]

Explain TCP Sliding Window flow control.

Official Model Answer & Marking Scheme [6 Marks]:

Dynamic receiver window size adjustment indicating how many bytes sender can transmit before requiring ACK.

Question 40 • Medium [6 Marks]

Explain TCP 4-way FIN connection termination.

Official Model Answer & Marking Scheme [6 Marks]:

Sender sends FIN -> Receiver ACKs -> Receiver sends FIN -> Sender ACKs.

Question 45 • Hard [7 Marks]

Spanning Tree Protocol (STP 802.1D) Port States

Official Model Answer & Marking Scheme [7 Marks]:

Blocking -> Listening -> Learning -> Forwarding (Prevents Layer 2 switching loops).

Question 46 • Hard [8 Marks]

Wireshark PCAP Hex Frame Extraction

Official Model Answer & Marking Scheme [8 Marks]:

Bytes 0-5: Dest MAC; Bytes 6-11: Source MAC; Bytes 12-13: EtherType (0x0800 IPv4); Byte 14+: IP Header.

Question 47 • Hard [7 Marks]

STP Root Bridge Election Algorithm

Official Model Answer & Marking Scheme [7 Marks]:

Switch with lowest Bridge ID (Priority + MAC address) becomes Root Bridge.

Question 48 • Hard [6 Marks]
