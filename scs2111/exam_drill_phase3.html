Phase 3 Exam Drill: Cisco CLI & Topology Design

Cisco IOS syntax, VLAN configuration, IEEE 802.1Q trunking, Router-on-a-Stick (ROAS), and Spanning Tree loop prevention.

Part 1: Cisco IOS CLI Commands & VLAN Configuration

P3-Q01 [12 Marks]

Write the exact sequence of Cisco IOS CLI commands to perform the following setup on a Cisco 2960 Switch:

  1. Change switch hostname to Core-SW01 [2 Marks].
  2. Create VLAN 10 named ADMIN and VLAN 20 named STUDENTS [4 Marks].
  3. Configure port FastEthernet 0/5 as an Access Port assigned to VLAN 10 [3 Marks].
  4. Configure port GigabitEthernet 0/1 as an 802.1Q Trunk Port connected to the main router [3 Marks].
Official NUST Cisco CLI Model Answer [12 Marks]: 

! 1. Hostname Setup [2 Marks]
Switch> enable
Switch# configure terminal
Switch(config)# hostname Core-SW01

! 2. VLAN Creation [4 Marks]
Core-SW01(config)# vlan 10
Core-SW01(config-vlan)# name ADMIN
Core-SW01(config-vlan)# exit
Core-SW01(config)# vlan 20
Core-SW01(config-vlan)# name STUDENTS
Core-SW01(config-vlan)# exit

! 3. Access Port Assignment [3 Marks]
Core-SW01(config)# interface FastEthernet 0/5
Core-SW01(config-if)# switchport mode access
Core-SW01(config-if)# switchport access vlan 10
Core-SW01(config-if)# no shutdown
Core-SW01(config-if)# exit

! 4. Trunk Port Assignment [3 Marks]
Core-SW01(config)# interface GigabitEthernet 0/1
Core-SW01(config-if)# switchport mode trunk
Core-SW01(config-if)# switchport trunk allowed vlan 10,20
Core-SW01(config-if)# end
Core-SW01# copy running-config startup-config

Part 2: Inter-VLAN Routing & STP Mechanics

P3-Q02 [8 Marks]

Explain the operation of Router-on-a-Stick (ROAS) inter-VLAN routing. Why are sub-interfaces and IEEE 802.1Q encapsulation required on the router physical interface?

Official NUST Marking Scheme [8 Marks]:
  • ROAS Core Concept [2 Marks]: Allows a single physical router interface to route traffic between multiple distinct VLANs over a single trunk link.
  • Sub-interfaces Role [3 Marks]: Virtual logical interfaces created on one physical router port (e.g. Gi0/0/0.10 and Gi0/0/0.20), each acting as the default gateway for its respective VLAN IP subnet.
  • 802.1Q Tagging [3 Marks]: Enforces encapsulation dot1Q 10 on sub-interfaces so the router can read incoming VLAN tags from the switch trunk link and route packets across subnets before re-tagging.
