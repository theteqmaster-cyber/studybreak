Exam Drill Phase 4 of 4 70 Individual Questions (Strict Difficulty Order)

Phase 4 Master Exam Bank: Enterprise Defense, Wireless & Field Diagnostics

Complete 70-question university question bank covering 802.11 wireless CSMA/CA, WPA3 enterprise defense, Cisco ACL rules, NAT/PAT, Wireshark PCAPs, and industrial rack diagnostics.

Part 1: Easy / Foundational Questions (Questions 01 – 30)

Question 01 • Easy [4 Marks]

What is IEEE 802.11?

Official Model Answer & Marking Scheme [4 Marks]:

The standard governing Wireless Local Area Networks (WLAN / Wi-Fi).

Question 02 • Easy [5 Marks]

List Wi-Fi standards evolution.

Official Model Answer & Marking Scheme [5 Marks]:

802.11a (5GHz 54Mbps), 802.11b (2.4GHz 11Mbps), 802.11g (2.4GHz 54Mbps), 802.11n (Wi-Fi 4 600Mbps), 802.11ac (Wi-Fi 5 6.9Gbps), 802.11ax (Wi-Fi 6 9.6Gbps).

Question 03 • Easy [3 Marks]

What are the 3 non-overlapping 2.4 GHz channels?

Official Model Answer & Marking Scheme [3 Marks]:

Channels 1, 6, and 11.

Question 04 • Easy [4 Marks]

Why does Wi-Fi use CSMA/CA instead of CSMA/CD?

Official Model Answer & Marking Scheme [4 Marks]:

Wireless radios operate Half-Duplex and cannot detect collisions while transmitting; CSMA/CA prevents collisions before they occur.

Question 05 • Easy [4 Marks]

What is the Hidden Node Problem?

Official Model Answer & Marking Scheme [4 Marks]:

Condition where two wireless clients cannot hear each other but both communicate with the same Access Point, causing collisions.

Question 06 • Easy [4 Marks]

What is the RTS/CTS handshake?

Official Model Answer & Marking Scheme [4 Marks]:

Request to Send / Clear to Send handshake reserving wireless channel airtime to eliminate hidden node collisions.

Question 07 • Easy [4 Marks]

What is Network Allocation Vector (NAV)?

Official Model Answer & Marking Scheme [4 Marks]:

Software timer inside wireless station frames setting channel reservation backoff countdown.

Question 08 • Easy [4 Marks]

List Wi-Fi encryption evolution.

Official Model Answer & Marking Scheme [4 Marks]:

WEP (flawed RC4) -> WPA (TKIP) -> WPA2 (AES-CCMP) -> WPA3 (SAE Dragonfly).

Question 09 • Easy [3 Marks]

What is an SSID?

Official Model Answer & Marking Scheme [3 Marks]:

Service Set Identifier - 32-character human-readable name identifying a WLAN network.

Question 10 • Easy [4 Marks]

What is WPA2-Personal vs WPA2-Enterprise?

Official Model Answer & Marking Scheme [4 Marks]:

Personal uses a single Pre-Shared Key (PSK); Enterprise uses 802.1X EAP authentication with a RADIUS server.

Question 11 • Easy [4 Marks]

What is a Firewall?

Official Model Answer & Marking Scheme [4 Marks]:

Network security system monitoring and filtering incoming/outgoing traffic based on security rules.

Question 12 • Easy [5 Marks]

Compare Packet Filtering vs Stateful Inspection Firewall.

Official Model Answer & Marking Scheme [5 Marks]:

Packet Filtering inspects isolated headers (L3/L4); Stateful Inspection tracks active connection state tables.

Question 13 • Easy [4 Marks]

What is NAT (Network Address Translation)?

Official Model Answer & Marking Scheme [4 Marks]:

Translates private internal IP addresses into public IP addresses for Internet access.

Question 14 • Easy [4 Marks]

What is PAT (Port Address Translation / NAT Overload)?

Official Model Answer & Marking Scheme [4 Marks]:

Translates multiple private internal IPs to a single public IP address using distinct source port numbers.

Question 15 • Easy [4 Marks]

What is a Cisco Access Control List (ACL)?

Official Model Answer & Marking Scheme [4 Marks]:

Sequential rule list permitting or denying IP packets based on source/dest IP and port numbers.

Question 16 • Easy [3 Marks]

State Standard ACL number range.

Official Model Answer & Marking Scheme [3 Marks]:

1-99 and 1300-1999.

Question 17 • Easy [3 Marks]

State Extended ACL number range.

Official Model Answer & Marking Scheme [3 Marks]:

100-199 and 2000-2699.

Question 18 • Easy [4 Marks]

What is the Standard ACL placement rule?

Official Model Answer & Marking Scheme [4 Marks]:

Place as close to the DESTINATION as possible.

Question 19 • Easy [4 Marks]

What is the Extended ACL placement rule?

Official Model Answer & Marking Scheme [4 Marks]:

Place as close to the SOURCE as possible.

Question 20 • Easy [4 Marks]

What is the Implicit Deny Any rule?

Official Model Answer & Marking Scheme [4 Marks]:

Unwritten final rule at end of every Cisco ACL that drops all unmatched traffic (deny ip any any).

Question 21 • Easy [4 Marks]

What is a VPN (Virtual Private Network)?

Official Model Answer & Marking Scheme [4 Marks]:

Encrypted software tunnel extending a private network across a public infrastructure.

Question 22 • Easy [4 Marks]

Compare Remote Access VPN vs Site-to-Site VPN.

Official Model Answer & Marking Scheme [4 Marks]:

Remote Access connects individual mobile users to office; Site-to-Site connects two static corporate branch networks.

Question 23 • Easy [4 Marks]

What is IPSec?

Official Model Answer & Marking Scheme [4 Marks]:

Suite of protocols securing IP communications via authentication and encryption.

Question 24 • Easy [5 Marks]

Compare IPSec AH vs ESP.

Official Model Answer & Marking Scheme [5 Marks]:

AH provides integrity and authentication without encryption; ESP provides integrity, authentication, AND data payload encryption.

Question 25 • Easy [4 Marks]

What is ARP Poisoning / Spoofing?

Official Model Answer & Marking Scheme [4 Marks]:

Attacker sends fake ARP replies mapping victim's IP to attacker's MAC address for MITM interception.

Question 26 • Easy [4 Marks]

What is a Man-in-the-Middle (MITM) attack?

Official Model Answer & Marking Scheme [4 Marks]:

Attacker secretly intercepts and alters communication between two trusting nodes.

Question 27 • Easy [4 Marks]

What is a DoS / DDoS attack?

Official Model Answer & Marking Scheme [4 Marks]:

Denial of Service attack overwhelming server/network resources with malicious traffic.

Question 28 • Easy [3 Marks]

What is the ping command used for?

Official Model Answer & Marking Scheme [3 Marks]:

Tests Layer 3 ICMP reachability and round-trip time latency to a target IP.

Question 29 • Easy [3 Marks]

What is the traceroute command used for?

Official Model Answer & Marking Scheme [3 Marks]:

Traces hop-by-hop router path to a destination by incrementing ICMP IP TTL values.

Question 30 • Easy [4 Marks]

What is the 7-layer troubleshooting methodology?

Official Model Answer & Marking Scheme [4 Marks]:

Systematic diagnostic workflow starting at Layer 1 (Physical cabling) up to Layer 7 (Application).

Question 34 • Medium [5 Marks]

Explain PAT Overload translation table mapping.

Official Model Answer & Marking Scheme [5 Marks]:

Internal 192.168.1.10:52144 -> PAT Router -> Public 203.0.113.1:52144.

Question 35 • Medium [5 Marks]

Wireshark PCAP analysis: Identifying TCP SYN Flooding DDoS.

Official Model Answer & Marking Scheme [5 Marks]:

Massive surge of TCP SYN packets from spoofed IPs without completing ACK handshakes.

Question 36 • Medium [5 Marks]

Wireshark PCAP analysis: Cleartext HTTP credentials.

Official Model Answer & Marking Scheme [5 Marks]:

Inspecting HTTP POST payload showing Authorization header or form fields containing unencrypted username/password.

Question 37 • Medium [5 Marks]

802.11 CSMA/CA Backoff Timer calculation.

Official Model Answer & Marking Scheme [5 Marks]:

Station selects random backoff slot within contention window CW_min to CW_max after DIFS timer.

Question 38 • Medium [6 Marks]

MIMO Spatial Streams throughput analysis.

Official Model Answer & Marking Scheme [6 Marks]:

Multiple antennas transmit independent data streams simultaneously over same frequency channel (2x2 doubles throughput).

Question 39 • Medium [5 Marks]

Channel Bonding trade-offs (20MHz -> 80MHz).

Official Model Answer & Marking Scheme [5 Marks]:

Doubles/quadruples throughput bandwidth but increases susceptibility to RF co-channel interference.

Question 40 • Medium [6 Marks]

Industrial Diagnostic Ticket: Resolving PoE camera disconnects.
