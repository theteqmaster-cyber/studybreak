💡 Exam Key Concept: PDU Transformation Order

During transmission down the OSI stack, raw application data receives control headers at each step: Data $\rightarrow$ Segment (Transport) $\rightarrow$ Packet (Network) $\rightarrow$ Frame (Data Link) $\rightarrow$ Bits (Physical). On arrival, the receiver strips off headers in reverse order (Decapsulation).
