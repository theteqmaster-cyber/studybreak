Phase 2 Exam Drill: Subnetting Math & Protocol Derivations

Deriving network IDs, broadcast addresses, FLSM/VLSM host allocations, binary ANDing, and CIDR prefix conversions.

Part 1: FLSM & Subnet Math Calculations

P2-Q01 [10 Marks]

An ISP assigns an organization the IP block 192.168.10.0/24. The network engineer must create four (4) equal-sized subnets using Fixed Length Subnet Masking (FLSM). Calculate:

  1. The new Subnet Mask in dotted decimal and new CIDR prefix notation [2 Marks].
  2. The Network ID for each of the 4 subnets [3 Marks].
  3. The Broadcast Address for each of the 4 subnets [3 Marks].
  4. The Usable IP Address Range for Subnet 2 [2 Marks].
Official NUST Step-by-Step Solution & Marking Scheme [10 Marks]:
1. Subnet Mask & CIDR Prefix [2 Marks]:
To make 4 subnets, we borrow $n$ bits where $2^n \ge 4 \rightarrow n = 2$ bits.
New Prefix: $/24 + 2 = \mathbf{/26}$.
Binary Mask: 11111111.11111111.11111111.11000000 $\rightarrow$ Dotted Decimal: $\mathbf{255.255.255.192}$.
2 & 3. Network IDs & Broadcast Addresses [6 Marks]:
Block Size = $256 - 192 = 64$ addresses per subnet.
• Subnet 1: Network ID: 192.168.10.0 | Broadcast: 192.168.10.63
• Subnet 2: Network ID: 192.168.10.64 | Broadcast: 192.168.10.127
• Subnet 3: Network ID: 192.168.10.128 | Broadcast: 192.168.10.191
• Subnet 4: Network ID: 192.168.10.192 | Broadcast: 192.168.10.255
4. Usable IP Range for Subnet 2 [2 Marks]:
Usable Range: 192.168.10.65 to 192.168.10.126 (Total 62 usable hosts).

Part 2: VLSM Variable Length Subnet Masking

P2-Q02 [15 Marks]

A university campus network has been allocated the IP block 10.1.1.0/24. Design a Variable Length Subnet Masking (VLSM) addressing scheme to satisfy the following departmental host requirements without wasting IP space:

  • Admin Department: 150 hosts
  • Faculty of Applied Science: 88 hosts
  • Marketing Department: 60 hosts
  • ICT Support: 25 hosts
Official NUST Step-by-Step Solution & Marking Scheme [15 Marks]:
Golden Rule [3 Marks]: Always sort departments in strictly descending order of host count before allocating VLSM blocks!
1. Admin (150 hosts) [4 Marks]:
Needs $h$ host bits where $2^h - 2 \ge 150 \rightarrow h = 8$ bits ($2^8 - 2 = 254$ hosts).
CIDR: $/32 - 8 = \mathbf{/24}$. Network ID: 10.1.1.0/24. Range: 10.1.1.1 - 10.1.1.254. Broadcast: 10.1.1.255.
2. Faculty of Applied Science (88 hosts) [4 Marks]:
Needs $h = 7$ bits ($2^7 - 2 = 126$ hosts). CIDR: $\mathbf{/25}$ (Mask 255.255.255.128).
Network ID: 10.1.2.0/25. Range: 10.1.2.1 - 10.1.2.126. Broadcast: 10.1.2.127.
3. Marketing (60 hosts) [2 Marks]:
Needs $h = 6$ bits ($2^6 - 2 = 62$ hosts). CIDR: $\mathbf{/26}$ (Mask 255.255.255.192).
Network ID: 10.1.2.128/26. Range: 10.1.2.129 - 10.1.2.190. Broadcast: 10.1.2.191.
4. ICT Support (25 hosts) [2 Marks]:
Needs $h = 5$ bits ($2^5 - 2 = 30$ hosts). CIDR: $\mathbf{/27}$ (Mask 255.255.255.224).
Network ID: 10.1.2.192/27. Range: 10.1.2.193 - 10.1.2.222. Broadcast: 10.1.2.223.
