Exam Drill Phase 2 of 4 70 Individual Questions (Strict Difficulty Order)

Phase 2 Master Exam Bank: IP Addressing & Subnetting Math

Complete 70-question university question bank covering CIDR bit masking, FLSM, VLSM 25-mark derivations, Magic Number block sizes, Cisco Wildcard masks, and IPv6 parsing.

Part 1: Easy / Foundational Questions (Questions 01 – 30)

Question 01 • Easy [4 Marks]

What is an IPv4 Address?

Official Model Answer & Marking Scheme [4 Marks]:

An IPv4 address is a 32-bit logical software address assigned to network interfaces to uniquely identify hosts on an IP network.

Question 02 • Easy [3 Marks]

How many bits are in an IPv4 address?

Official Model Answer & Marking Scheme [3 Marks]:

An IPv4 address contains exactly 32 bits divided into four 8-bit octets.

Question 03 • Easy [3 Marks]

What is dotted-decimal notation?

Official Model Answer & Marking Scheme [3 Marks]:

Dotted-decimal notation represents 32-bit binary IP addresses as four decimal numbers separated by dots (e.g. 192.168.1.1).

Question 04 • Easy [4 Marks]

Convert binary 11000000.10101000.00000001.00000001 to decimal.

Official Model Answer & Marking Scheme [4 Marks]:

192.168.1.1

Question 05 • Easy [4 Marks]

Convert decimal 10.0.0.1 to binary.

Official Model Answer & Marking Scheme [4 Marks]:

00001010.00000000.00000000.00000001

Question 06 • Easy [4 Marks]

State the 8 positional binary values of an octet.

Official Model Answer & Marking Scheme [4 Marks]:

128, 64, 32, 16, 8, 4, 2, 1

Question 07 • Easy [4 Marks]

What is a Subnet Mask?

Official Model Answer & Marking Scheme [4 Marks]:

A Subnet Mask is a 32-bit value of consecutive 1s followed by consecutive 0s that separates the Network ID from the Host ID.

Question 08 • Easy [4 Marks]

What is CIDR notation?

Official Model Answer & Marking Scheme [4 Marks]:

Classless Inter-Domain Routing (CIDR) notation expresses the subnet mask as a slash followed by the count of network prefix 1-bits (/N).

Question 09 • Easy [3 Marks]

Convert /24 to dotted-decimal.

Official Model Answer & Marking Scheme [3 Marks]:

255.255.255.0

Question 10 • Easy [3 Marks]

Convert /26 to dotted-decimal.

Official Model Answer & Marking Scheme [3 Marks]:

255.255.255.192

Question 11 • Easy [3 Marks]

Convert /27 to dotted-decimal.

Official Model Answer & Marking Scheme [3 Marks]:

255.255.255.224

Question 12 • Easy [3 Marks]

Convert /28 to dotted-decimal.

Official Model Answer & Marking Scheme [3 Marks]:

255.255.255.240

Question 13 • Easy [3 Marks]

Convert /30 to dotted-decimal.

Official Model Answer & Marking Scheme [3 Marks]:

255.255.255.252

Question 14 • Easy [4 Marks]

What is a Network Address (Network ID)?

Official Model Answer & Marking Scheme [4 Marks]:

The first address in a subnet (all host bits set to 0), representing the entire sub-network.

Question 15 • Easy [4 Marks]

What is a Broadcast Address?

Official Model Answer & Marking Scheme [4 Marks]:

The last address in a subnet (all host bits set to 1), used to send traffic to all nodes in that subnet.

Question 16 • Easy [4 Marks]

State the usable host formula.

Official Model Answer & Marking Scheme [4 Marks]:

2^h - 2 (where h is the number of host bits).

Question 17 • Easy [4 Marks]

Why do we subtract 2 in the usable host formula?

Official Model Answer & Marking Scheme [4 Marks]:

We subtract 2 because the Network ID (all 0s) and Broadcast ID (all 1s) cannot be assigned to individual hosts.

Question 18 • Easy [4 Marks]

What is Classful IPv4 Addressing?

Official Model Answer & Marking Scheme [4 Marks]:

Legacy IP scheme dividing the 32-bit address space into fixed-length classes (Class A, B, C, D, E).

Question 19 • Easy [4 Marks]

State Class A range and default mask.

Official Model Answer & Marking Scheme [4 Marks]:

Range: 1.0.0.0 to 127.255.255.255. Default Mask: 255.0.0.0 (/8).

Question 20 • Easy [4 Marks]

State Class B range and default mask.

Official Model Answer & Marking Scheme [4 Marks]:

Range: 128.0.0.0 to 191.255.255.255. Default Mask: 255.255.0.0 (/16).

Question 21 • Easy [4 Marks]

State Class C range and default mask.

Official Model Answer & Marking Scheme [4 Marks]:

Range: 192.0.0.0 to 223.255.255.255. Default Mask: 255.255.255.0 (/24).

Question 22 • Easy [3 Marks]

What is Class D used for?

Official Model Answer & Marking Scheme [3 Marks]:

Multicast group communication (Range: 224.0.0.0 to 239.255.255.255).

Question 23 • Easy [3 Marks]

What is Class E used for?

Official Model Answer & Marking Scheme [3 Marks]:

Experimental and research purposes (Range: 240.0.0.0 to 255.255.255.255).

Question 24 • Easy [4 Marks]

What is RFC 1918 Private IP addressing?

Official Model Answer & Marking Scheme [4 Marks]:

Special non-routable IP ranges reserved for local private LAN networks to conserve IPv4 space.

Question 25 • Easy [3 Marks]

State the RFC 1918 Class A private block.

Official Model Answer & Marking Scheme [3 Marks]:

10.0.0.0/8 (10.0.0.0 to 10.255.255.255)

Question 26 • Easy [3 Marks]

State the RFC 1918 Class B private block.

Official Model Answer & Marking Scheme [3 Marks]:

172.16.0.0/12 (172.16.0.0 to 172.31.255.255)

Question 27 • Easy [3 Marks]

State the RFC 1918 Class C private block.

Official Model Answer & Marking Scheme [3 Marks]:

192.168.0.0/16 (192.168.0.0 to 192.168.255.255)

Question 28 • Easy [3 Marks]

What is the Loopback address 127.0.0.1 used for?

Official Model Answer & Marking Scheme [3 Marks]:

Testing local TCP/IP software stack implementation on the host without sending traffic over physical wire.

Question 29 • Easy [4 Marks]

What is APIPA (Automatic Private IP Addressing)?

Official Model Answer & Marking Scheme [4 Marks]:

Range 169.254.0.0/16 assigned automatically by Windows/OS when a DHCP server fails to respond.

Question 30 • Easy [4 Marks]

What is Bitwise AND operation?

Official Model Answer & Marking Scheme [4 Marks]:

A binary logic operation where 1 AND 1 = 1, and any other combination = 0, used by routers to extract Network ID.

Part 2: Medium / Intermediate Questions (Questions 31 – 40)

Question 31 • Medium [6 Marks]

Calculate Network IP for 192.168.10.75/26 using Bitwise AND.

Official Model Answer & Marking Scheme [6 Marks]:

Mask /26 = 255.255.255.192. 75 AND 192 = 64. Network IP = 192.168.10.64/26.

Question 32 • Medium [6 Marks]

Calculate Broadcast IP for 192.168.10.75/26.

Official Model Answer & Marking Scheme [6 Marks]:

Block size S = 256 - 192 = 64. Next net = 128. Broadcast = 192.168.10.127.

Question 33 • Medium [5 Marks]

Calculate Usable Host Range for 192.168.10.75/26.

Official Model Answer & Marking Scheme [5 Marks]:

First usable = 192.168.10.65. Last usable = 192.168.10.126.

Question 34 • Medium [5 Marks]

State the Magic Number / Block Size formula.

Official Model Answer & Marking Scheme [5 Marks]:

Block Size S = 256 - Mask Octet Value.

Question 35 • Medium [5 Marks]

Calculate Block Size for /27.

Official Model Answer & Marking Scheme [5 Marks]:

S = 256 - 224 = 32.

Question 36 • Medium [5 Marks]

Calculate Block Size for /28.

Official Model Answer & Marking Scheme [5 Marks]:

S = 256 - 240 = 16.

Question 37 • Medium [5 Marks]

Calculate Block Size for /30.

Official Model Answer & Marking Scheme [5 Marks]:

S = 256 - 252 = 4.

Question 38 • Medium [6 Marks]

Subnet 192.168.1.0/24 into 4 equal subnets using FLSM.

Official Model Answer & Marking Scheme [6 Marks]:

Borrow 2 bits => CIDR /26 (Mask 255.255.255.192). Subnets: 192.168.1.0/26, 192.168.1.64/26, 192.168.1.128/26, 192.168.1.192/26.

Question 39 • Medium [5 Marks]

Calculate Cisco Wildcard Mask for /24.

Official Model Answer & Marking Scheme [5 Marks]:

Wildcard = 255.255.255.255 - 255.255.255.0 = 0.0.0.255.

Question 40 • Medium [5 Marks]

Calculate Cisco Wildcard Mask for /26.

Official Model Answer & Marking Scheme [5 Marks]:

Wildcard = 255.255.255.255 - 255.255.255.192 = 0.0.0.63.

Question 46 • Hard [7 Marks]

IPv6 128-bit Structure & Zero Compression Rules

Official Model Answer & Marking Scheme [7 Marks]:

8 hextets of 16 bits each. Rule 1: Omit leading zeros. Rule 2: Compress single longest contiguous run of zeros with double colon ::.

Automatically configured on every IPv6 interface using fe80::/10 prefix combined with EUI-64 or random Interface ID.

Question 49 • Hard [6 Marks]

IPv6 Multicast Addresses (ff02::1 vs ff02::2)

Official Model Answer & Marking Scheme [6 Marks]:

ff02::1 reaches all IPv6 nodes on link; ff02::2 reaches all IPv6 routers on link.
