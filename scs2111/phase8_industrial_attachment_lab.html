2. Network Server Cabinet Component Anatomy

Hardware Anatomy

Network Rack Layout & Patching

  • Patch Panels: Wall drop cables terminate into rear RJ45 keystone jacks on the patch panel. Short patch cords bridge from panel to switch ports.
  • Managed Switch Stack: Interconnected via high-speed 10Gbps SFP+ stack cables.
  • Fiber Optics Transceiver Box: Converts ISP fiber glass line into copper RJ45 WAN input.
  • UPS Power Backup: Uninterruptible Power Supply shielding switches from sudden power cuts.
Redundancy Rule

ISP Primary vs. Secondary WAN Failover

Enterprises cannot afford total network downtime. Always deploy dual ISP WAN connections:

  • Primary Provider (e.g. Liquid Intelligent Tech): High speed, lower cost per GB, carries 95% of daily traffic.
  • Secondary Provider (e.g. TelOne / Dedicated Microwave): Higher cost per GB, kept active strictly as automatic failover backup when primary fiber suffers cut.

3. Cisco Packet Tracer Lab 1: Building a Simple Switched Network

Step-by-Step Cisco Packet Tracer Practical Lab Guide

Step 1: Open Packet Tracer. From End Devices, drag 2 PCs (PC0 and PC1) onto workspace.
Step 2: From Network Devices -> Switches, select a Cisco 2960 24-Port Switch.
Step 3: Select Connections -> Copper Straight-Through Cable.
        - Connect PC0 FastEthernet0 to Switch FastEthernet 0/1.
        - Connect PC1 FastEthernet0 to Switch FastEthernet 0/2.
Step 4: Click PC0 -> Desktop tab -> IP Configuration.
        - Set IP Address: 192.168.1.10
        - Set Subnet Mask: 255.255.255.0
Step 5: Click PC1 -> Desktop tab -> IP Configuration.
        - Set IP Address: 192.168.1.11
        - Set Subnet Mask: 255.255.255.0
Step 6: Verify ICMP Connectivity:
        - Open Command Prompt on PC0.
        - Execute command: ping 192.168.1.11
        - Output should show: 4 packets sent, 4 received (0% loss).
