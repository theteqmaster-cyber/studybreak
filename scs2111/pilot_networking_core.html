🌐 SCS2111: Data Communications & Networking

Pilot Card — Core Concepts, Protocol Stacks & OSI Layers

1. The OSI 7-Layer Reference Model

Memory Device: All People Seem To Need Data Processing (Application, Presentation, Session, Transport, Network, Data Link, Physical).

Key Protocols: HTTP/S, DNS, TCP, UDP, IP, ARP, Ethernet.

2. TCP vs UDP Dynamics

TCP (Transmission Control Protocol): Connection-oriented, 3-Way Handshake (SYN, SYN-ACK, ACK), reliable delivery with sequence numbers and sliding window flow control.

UDP (User Datagram Protocol): Connectionless, lightweight, low-latency streaming & real-time communication.

3. IP Addressing & Subnetting

CIDR notation (e.g. 192.168.1.0/24), Subnet Masks, Network ID, Broadcast Address, and Private IP Ranges (RFC 1918).
