5.2 Dependencies, Lead/Lag & Forward/Backward Pass

Precedence Dependencies & Passes

FS
Finish-to-Start
Task B cannot start until Task A finishes (most common, e.g., Code → Test).
SS
Start-to-Start
Task B cannot start until Task A starts (allows parallel overlap).
FF
Finish-to-Finish
Task B cannot finish until Task A finishes (e.g., Docs & Build).
SF
Start-to-Finish
Task B cannot finish until Task A starts (rare shift handovers).
FORWARD PASS (ES & EF)

Calculates earliest dates left-to-right. When merging two or more predecessors, take the MAXIMUM (largest) Earliest Finish to set the successor's Earliest Start!

EF = ES + Duration (or ES + D − 1 in 1-indexed days)
BACKWARD PASS (LF & LS)

Calculates latest non-delaying dates right-to-left. When branching back to multiple successors, take the MINIMUM (smallest) Latest Start! Lead = negative lag (overlaps); Lag = forced delay.

LS = LF − Duration | Float = LS − ES = LF − EF

Critical Path, Slack & Compression

  • Sequence of activities where ES = LS and EF = LF.

  • Free Slack: Max delay before delaying the next activity's ES.

5.4 Program Evaluation & Review Technique (PERT)

Probabilistic PERT Time & Variance

3-POINT ESTIMATESUNCERTAIN WORK
  • Optimistic Time (a): Best-case duration if everything goes right.
  • Most Likely Time (m): Realistic normal duration.
  • Pessimistic Time (b): Worst-case duration if major delays hit.
Expected Duration: t_e = (a + 4m + b) / 6
PERT assigns 4× weight to Most Likely (m) in a Beta probability distribution.
STANDARD DEVIATION & VARIANCEEXAM MATH
Task SD: σ = (b − a) / 6
Task Variance: σ² = [(b − a) / 6]²
Path SD: σ_path = √( Σ σ_i² )
Never add task SDs directly! Sum the variances (σ²) along the critical path first, then take the square root.

CRITICAL CHAIN (CCPM) BUFFERS

CCPM emphasizes resource dependencies and removes hidden per-task padding, consolidating safety into explicit buffers:

3 Buffer Types

Project Buffer (end of critical chain) • Feeding Buffer (where non-critical chains merge in) • Resource Buffer (alert flag, not time).

Penetration Action Triggers

1st Third: Monitor only • Middle Third: Investigate & make get-well plan • Final Third: Immediate corrective action.
